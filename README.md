# TioTio

O TioTio é um sistema web desenvolvido para auxiliar motoristas de transporte escolar no gerenciamento e controle das informações relacionadas à sua atividade. 

O sistema tem como objetivo centralizar informações sobre motoristas, veículos, alunos, responsáveis, escolas, rotas, contratos, gastos, pagamentos e notificações. Dessa forma, busca facilitar a organização das informações utilizadas no dia a dia do motorista, além de permitir um melhor acompanhamento dos custos, documentos e demais responsabilidades relacionadas ao transporte escolar.
